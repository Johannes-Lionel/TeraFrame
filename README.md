# TerraFrame

TerraFrame is a responsive image-search interface where people will be able to search a topic and explore a grid of visual results. I chose an earthy forest-green, cream, and orange palette to give the app a calm, editorial feel rather than a typical neon search-tool look. The quick-pick topic chips help visitors get ideas when they are not sure what to search for. The empty-state illustration and message make the blank results area feel intentional while the image-search functionality is built in Part 2.

Part 1 is complete: the responsive interface is ready for image-search functionality in Part 2.
